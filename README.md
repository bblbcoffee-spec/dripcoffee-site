# 大雀鳥小雀鳥咖啡｜離線網站下載包

這份資料夾是從公開網址 `https://dripcoffee-kblffztf.manus.space/` 擷取並整理的靜態離線版本。首頁、樣式表、JavaScript 與頁面圖片已放在本機，並已移除 Manus 線上編輯器 runtime 與分析追蹤腳本。

## 開啟方式

建議在此資料夾內啟動簡易靜態伺服器，再使用瀏覽器開啟首頁。若電腦已安裝 Python 3，可以在終端機執行：

```bash
python3 -m http.server 8000
```

接著開啟 `http://localhost:8000/`。也可以嘗試直接雙擊 `index.html`；若瀏覽器因安全限制阻擋 ES module 或本機資源，請改用上述靜態伺服器方式。
